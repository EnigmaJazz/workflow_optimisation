## Working method that proved out (keep using it)
- **Strong model** (Claude, now in an advisory role): writes the spec and the acceptance tests, and
  confirms RED with no vacuous passes. Absence assertions need a positive control.
- **Cheaper writer:** implements to GREEN without editing the spec or tests. On a contradiction
  it stops and reports.
- **Advice before code:** dispatch from the OpenCode TUI via `gentle-orchestrator` → Task →
  `advisor-*`. Scripted `opencode run --agent advisor-*` silently falls back to the primary
  agent (Q51).
- **Native review per work unit,** never the accumulated branch. Assess from the last reviewed
  boundary (`--base-ref <boundary> --committed-only`). The stop hook's selectorless STATUS can
  propose the whole branch; prefer the work-unit candidate.
